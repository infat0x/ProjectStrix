# Project Strix — Podman & Container Configuration

This directory contains the container specifications and environment templates for running Project Strix via Podman and Podman Compose (or Docker Compose).

---

## 📁 Files

- `Dockerfile`: Production multi-stage image definition (Node.js 20, Python 3, Strix CLI, Prisma, Next.js).
- `podman-compose.yml`: Multi-container stack definition (`strix-db` and `strix-dashboard`).
- `.env.podman.example`: Environment variable template.
- `.env.podman`: (Auto-generated by `runner/podman/deploy.py` at deploy time, git-ignored).

---

## 🚀 Execution

To deploy or manage this stack, run the orchestrators located in `runner/podman/`:

- **Linux / VPS / WSL2**:
  ```bash
  python3 runner/podman/deploy.py
  # or: bash runner/podman/deploy.sh
  ```
- **Windows (PowerShell)**:
  ```powershell
  .\runner\podman\deploy.ps1
  ```
- **Windows (Command Prompt / Double-Click)**:
  ```cmd
  runner\podman\deploy.bat
  ```
